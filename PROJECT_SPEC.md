# Project Spec (Paper-driven)

Primary claim:
Choquet integral aggregation driven by well-designed client reliability scoring improves robustness/fairness under heterogeneous client quality.

Phase plan:
- Phase 0: scaffold + interfaces + logging (no datasets)
- Phase 1: synthetic (ground-truth reliability)
- Phase 2: CIFAR100
- Phase 3: UNSW-NB15
- Later: UCI HAR, C-MAPSS, HAM10000, ISIC2019, FitRec

Strict constraint: NO Sugeno.
